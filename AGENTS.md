# Project agent memory

This file is the project's committed home for project-intrinsic agent knowledge: build, test, release, architecture, and sharp-edge notes that should travel with the code.

1. Static site on GitHub Pages under `/weather/`. No build step, no backend, no secrets in the client. Keep every path relative. Layout, local serving, and tests: see README.md.
2. Data honesty is the product: model, station (SNOTEL), and official (CAIC) values stay labeled separately; missing is `null` and renders as a dash, never zero; model spread is never called a probability. Accumulation goes through `integrate()` in `core.js`, which refuses incomplete windows.
3. Open-Meteo model ids in `MODELS` (locations.js) were verified against Colorado coordinates. Some "seamless" ids (MET Norway, KNMI, DMI) silently fall back to ECMWF outside Europe, and GraphCast, BOM, and KMA return no snowfall here; re-probe before adding ids.
4. `data/grid.json` and `data/model-ranking.json` are generated by `scripts/` via `.github/workflows/data.yml`; do not hand-edit them. The owner edits `data/skiers.csv`, `data/facts.csv`, and `data/guestbook.json` directly on GitHub.
5. SNOTEL daily values are end-of-day readings (verified against hourly data): new snow on day D is depth(D) minus depth(D-1). See `measuredDay` in `core.js`.
6. MapLibre is pinned to the 5.x UMD build with SRI in `map.js`. 6.x is ESM-only and loads its worker from the CDN origin, which breaks cross-origin; do not bump to 6 without self-hosting. Use `map.getSource(...)` guards, not `map.isStyleLoaded()`, before updating layers; the latter is false while tiles load and silently drops updates.
